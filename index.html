Dressing Boost — activation des mises à jour

Un bloc chiffré par téléphone. Aucun secret dans l’APK, aucun serveur.

Cette page n’envoie rien. Elle chiffre vos informations dans votre navigateur avec la clé publique affichée par votre téléphone. Aucun appel réseau, aucun stockage, aucune mesure d’audience. Vous pouvez la déconnecter et la rouvrir : elle fonctionne hors ligne.

1Sur votre téléphone

Au premier lancement, l’app affiche l’écran « Activation requise » : touchez « Copier la clé » et collez-la ci-dessous. Cette clé est propre à cet appareil : le bloc obtenu ne fonctionnera nulle part ailleurs. L’app reste verrouillée tant que l’activation n’a pas réussi.

Base64 d’une clé SPKI RSA. Les retours à la ligne et l’en-tête PEM sont acceptés.

2Votre accès au dépôt privé

Créez un token « fine-grained » limité à ce dépôt, avec le droit Contents : Read-only. Un token par téléphone, révocable à tout moment sur GitHub.

Le token n’est ni affiché ni conservé : le champ est vidé après la génération, réussie ou non.

3Rapportez le bloc dans l’app

Dans l’écran d’activation de l’app : collez le bloc dans « Bloc chiffré reçu » puis touchez « Activer cet appareil ». L’app démarre ensuite normalement. Pour les mises à jour : Réglages → Mises à jour → « Vérifier », « Télécharger », puis « Installer ».

Bon à savoir

Une activation obligatoireL’APK s’installe sans jeton, mais la première ouverture exige l’activation décrite ici. Le token sert ensuite à rechercher les mises à jour.
Bloc non transmissibleChiffré pour un seul appareil : le copier sur un autre téléphone ne fonctionnera pas.
Révocation simpleSupprimez le token sur GitHub : l’app n’a plus accès aux releases, sans toucher à vos données.
Aucune installation automatiqueLe téléchargement vérifie l’empreinte SHA-256, puis Android demande votre confirmation.
Page statique autonome — aucun service externe, aucune donnée collectée.
